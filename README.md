# 🎓 Student Management System

A simple, menu-driven **Student Management System built using Python**. This project was created as part of my Python learning journey to practice fundamental programming concepts by building a practical application.

## 📌 Project Overview

The Student Management System allows users to manage student records through an interactive command-line interface. Users can add, view, search, update, and delete student information, as well as perform basic analysis on student marks.

## ✨ Features

- **Add Student:** Add a new student record with student ID, name, age, marks, and grade.
- **Display All Students:** View the available student records.
- **Search Student:** Find a student's details using their ID.
- **Update Student Marks:** Modify the marks of an existing student.
- **Delete Student:** Remove a student record using their ID.
- **Calculate Average Marks:** Calculate the average marks of all students.
- **Students Scoring Above 80:** Display students who scored more than 80 marks.
- **Input Validation:** Handle invalid inputs using exception handling.
- **Interactive Menu:** Navigate through the available operations using a menu-driven interface.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Concepts:** Variables, data types, dictionaries, conditional statements, loops, functions, and exception handling
- **Data Structure:** Nested dictionaries
- **Interface:** Command-line interface (CLI)

## ⚙️ Requirements

- Python 3 installed on your system
- A code editor such as VS Code (optional)

## 🚀 How to Run the Project

**1. Clone the repository**

```bash
git clone <your-github-repository-url>
```

**2. Navigate to the project directory**

```bash
cd student-management-system
```

**3. Run the Python program**

Replace `main.py` with your actual Python filename if it is different.

```bash
python main.py
```

On some systems, you may need to use:

```bash
python3 main.py
```

## 🖥️ How to Use

1. Run the Python script.
2. Select an option from the displayed menu.
3. Enter the requested student information.
4. Follow the prompts to perform the selected operation.
5. Type `exit` or `stop` to close the application.
